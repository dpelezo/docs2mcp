# Contributing

Issues and pull requests are welcome.

1. Install [uv](https://docs.astral.sh/uv/) and [just](https://just.systems), then run `just setup`.
2. Create a branch, make one focused change, and add tests for it.
3. Run `just check` (lint, Pyright strict, unit tests). CI runs the same checks.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages and the pull request title.

The rules in [AGENTS.md](AGENTS.md) apply to human contributors too.
